# Em quem votar?

Quiz estático em que a pessoa escolhe entre propostas de governo **sem saber de quem são**. No fim, vê o percentual de afinidade com cada candidatura do 2º turno de 2026 e só então a autoria de cada proposta, com a fonte.

## Regra de neutralidade

- Nenhum nome, partido, slogan ou programa identificável aparece durante o quiz.
- Cada pergunta tem uma proposta de cada lado, com tamanho e tom parecidos, em ordem A/B sorteada.
- Mesmo número de perguntas por tema para os dois lados; o resultado é só a contagem das escolhas, sem pesos.
- "Nenhuma das duas / Não sei" não conta para ninguém.
- Não é recomendação de voto. Sem login e sem cookies. Se a contagem anônima estiver ativa, o site avisa na tela e só registra as escolhas, sem nome, IP ou identificação.

As propostas vêm dos planos de governo registrados no TSE, de reportagens sobre eles e de entrevistas dos candidatos, e foram generalizadas para não revelar o autor.

Site: HTML + CSS + JS puro (`index.html`).
